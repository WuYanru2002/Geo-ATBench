# POI Range Analysis

This folder contains three supplementary files:

- `waves_ap_by_poi_range.png`: AP of the Waves class under different POI extraction ranges.
- `best_range_by_sound_event.png`: Best-performing POI extraction range for each sound-event class.
- `waves_poi_matrix.csv`: Additional POI values for Waves across different spatial bands and OSM feature categories.
