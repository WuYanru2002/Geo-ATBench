# Per-Class AP Confidence Intervals

This folder provides the number of positive test clips for all 28 sound-event classes, per-class Average Precision (AP) estimates with 95% bootstrap confidence intervals, and the corresponding GeoFusion-Early-AST source predictions.

Files:

- `per_class_average_precision_95CI.csv`: Test-set class counts, AP, and 95% confidence intervals for each event class.
- `bootstrap_average_precision_values.csv`: Per-class AP values from 1,000 bootstrap resamples.
- `GeoFusion-Early-AST_raw_predictions.csv`: Source predictions used for the AP and confidence-interval analysis.
