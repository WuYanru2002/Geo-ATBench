# Analysis

This directory groups the detailed analyses supporting the Geo-ATBench paper.

## GSC and Spatial Analysis

`GSC_and_Spatial_Analysis/` contains OSM query examples and GSC construction materials.

## Temporal OSM Analysis

`Data_Overlap_and_Temporal_Analysis/Temporal_OSM_Analysis/` contains temporal OSM analyses.

## Robustness and Representation Analysis

`Robustness_and_Representation_Analysis/t-SNE/` contains audio representation visualizations.
