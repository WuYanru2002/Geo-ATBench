# Geo-ATBench Version 1.1

Version 1.1 contains the current data, fixed split files, predictions, code, and result tables for the additional evaluation protocols and analyses.

| Material | Description |
|---|---|
| `splits/` | Fixed Train, Validation, and Test assignments. |
| `predictions/` | Model prediction files for the independent evaluation protocols. |
| `results/` | Aggregate results for the reported analyses. |
| `code/` | Analysis and evaluation procedures. |
| `MANIFEST.json` | File checksums and split-size checks. |
